Roslyn-based MCP server providing semantic code intelligence for .NET codebases. Its 67 tools cover navigation, call graphs, diagnostics and code fixes, safe refactoring, code-quality auditing, test intelligence, DI graphs, and IL and external-assembly inspection, exposed to AI coding assistants like Claude Code.

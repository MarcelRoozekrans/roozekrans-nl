A modular retrieval-augmented generation pipeline for .NET, built directly on the Microsoft.Extensions.AI abstractions rather than wrapping a single vendor. Chunking, embedding, retrieval, and generation are separate stages you can swap independently, so the same pipeline runs against whichever embedding model and vector store you already have.
